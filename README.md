# My Portfolio

Welcome to my personal portfolio repository! This project is built to showcase my skills, projects, and experiences. It is designed with a focus on aesthetics, performance, and responsiveness to ensure a seamless user experience.

## 🛠️ Tech Stack

This portfolio is built with the following technologies:

- **Astro**: Static site generator for blazing-fast websites.
- **TypeScript**: For type-safe and maintainable code.
- **Tailwind CSS**: To style the portfolio.
- **AWS CDK**: To deploy the website.
